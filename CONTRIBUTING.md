# Contributing to VLC Remote

First off, thank you for considering contributing to VLC Remote! It's people like you that make this a great tool for everyone.

## Code of Conduct

By participating in this project, you are expected to uphold our Code of Conduct. (Link to a CoC if you have one, or just follow general professional etiquette).

## How Can I Contribute?

### Reporting Bugs

- **Check if the bug has already been reported** by searching on GitHub under [Issues](https://github.com/jay-lenti/free-vlc-remote-app/issues).
- If you can't find an open issue addressing the problem, [open a new one](https://github.com/jay-lenti/free-vlc-remote-app/issues/new).
- Use the **Bug Report** template if available.

### Suggesting Enhancements

- **Check if the enhancement has already been suggested.**
- Open a new issue and use the **Feature Request** template.

### Pull Requests

1. **Fork the repo** and create your branch from `dev`.
2. **If you've added code that should be tested, add tests.**
3. **Ensure the test suite passes** (`flutter test`).
4. **Run analysis** to ensure no linting issues (`flutter analyze`).
5. **Issue that pull request!**

## Styleguide

### Flutter/Dart

- Follow the official [Dart Style Guide](https://dart.dev/guides/language/analysis-options).
- Use `flutter format .` before committing.
- Ensure all new features are covered by widget and/or unit tests.

### Commit Messages

- Use concise, descriptive commit messages.
- Reference issues and pull requests where appropriate.

## Setting up for Development

1. Install [Flutter SDK](https://docs.flutter.dev/get-started/install).
2. Clone your fork.
3. Run `flutter pub get`.
4. To test against a real VLC instance, follow the setup guide in the `README.md`.

Thanks again for your help!
