Privacy Policy

Last updated: May 2024

Data Collection

VLC Remote does not collect, store, or transmit any user data to external servers. The application is designed to operate entirely within your local area network (LAN).

Local Communication

The app communicates directly with your local VLC Media Player instance via HTTP requests using the IP address and port you provide. This information is stored only on your device to facilitate future connections and is never shared with the developers or any third parties.

Third-Party Services

This app does not include any third-party analytics or advertising frameworks.

Contact

If you have any questions about this Privacy Policy, please contact us via our GitHub Issues page.
